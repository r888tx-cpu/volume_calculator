⚡ Особенности запуска и производительность

При первичном (холодном) старте запуск приложения может занимать 10–12 секунд с кратковременной загрузкой процессора до 25–30%. При повторных запусках программа открывается существенно быстрее — около 4–5 секунд.

Технические причины:

  • В дистрибутив включено около 1500 внутренних файлов и динамических библиотек (высокопроизводительные математические ядра OpenBLAS, NumPy, SciPy, графическая подсистема Matplotlib/Tk), обеспечивающих полную автономность без необходимости устанавливать Python и внешние пакеты.
  • Программа распространяется как независимый инженерный инструмент без покупки дорогостоящего корпоративного сертификата цифровой подписи (EV Code Signing). В связи с этим встроенный антивирус Windows Defender (процесс MsMpEng.exe) при первом запуске выполняет глубокий многопоточный эвристический анализ каждого файла и библиотеки в папке _internal.

Как ускорить запуск до мгновенного:

Рекомендуется однократно добавить папку программы в исключения антивируса Windows:
Параметры Windows → Конфиденциальность и безопасность → Безопасность Windows → Защита от вирусов и угроз → Управление настройками → Исключения → Добавить исключение → Папка (выберите папку с программой).

1. Быстрый старт

1.1. Загрузите файл(ы) координат:

  • Через диалог — кнопка Импорт файла... (или Верх / Низ... для раздельных съёмок) в левой панели.
  • Перетаскиванием (Drag & Drop) — перетащить файл координат мышью в окно программы. Файл автоматически копируется в папку проекта и загружается.
  • Копированием (Copy & Paste) — скопировать файл координат в папку программы. Файл автоматически переносится в папку проекта и загружается.
  • Из списка проектов — выбрать проект в выпадающем списке. Загрузка и расчёт выполняются автоматически.
💡 Интеллектуальный импорт и авто-переопределение координат:
Если координаты в файле не соответствуют стандартному правилу 6/7 знаков (например, локальная строительная сетка с координатами вида 3299.100, 1616.200 или нестандартный порядок колонок), программа не показывает блокирующих сообщений об ошибках, а сразу открывает окно переопределения координат (🔀 Переопределение координат (X, Y, Z)). В окне отображается предпросмотр строк файла, где можно выбрать соответствие столбцов и нажать «✓ Применить координаты».

1.2. Переопределите контур фигуры

После загрузки программа автоматически выполняет расчёт объёма (если контур определён) и открывает вкладку «2D Схема в плане».

Для гибкой и быстрой корректировки контура без необходимости его полной переделки доступны удобные интерактивные операции прямо на чертеже:

  • Встраивание точки в ближайшее ребро — Двойной клик ЛКМ по свободной точке. Программа автоматически находит ближайший отрезок контура и встраивает точку в нужную позицию без искажения порядка обхода и без самопересечений.
  • Замена вершины контура (перетаскивание) — Зажмите ПКМ на вершине контура и перетащите курсор на новую точку. Контур эластично перестроится на лету.
  • Удаление точки из контура — одиночный клик ЛКМ по вершине контура.
  • Добавление в конец — одиночный клик ЛКМ по свободной точке.
  • Контекстное меню точки (ПКМ) — клик правой кнопкой мыши по любой точке вызывает меню: «▲ Перенести в верхнюю поверхность», «▼ Перенести в нижнюю поверхность» или «❌ Удалить точку».
  • Отмена действий — кнопка ↩ Отмена в панели слева, клик ПКМ на свободном месте схемы или сочетание Ctrl+Z. Кнопка Сброс на панели слева или красная кнопка Сброс контура на самой вкладке схемы полностью очищают контур.

При любом изменении контура объём пересчитывается автоматически, результаты моментально обновляются на всех вкладках.

1.3. Выделение группы точек рамкой (Box Selection), пакетные действия и контроль импорта

🔍 Контроль качества импорта и разделения поверхностей:
Для надёжного контроля импорта и классификации точек крайне полезен визуальный анализ на вкладках «3D Поверхности» и «Картограмма масс»:
  • Вкладка «3D Поверхности» — наглядно отображает пространственное взаиморасположение поверхностей в 3D. Любые ошибочно классифицированные точки (например, точка дна, случайно отнесённая к верху, или наоборот) сразу видны как неестественные пики («иглы») или провалы на трёхмерной модели.
  • Вкладка «Картограмма масс» — цветовая карта распределения мощности пласта $\Delta H$ моментально выявляет локальные аномалии толщины, нулевые зоны и перепады отметок.
Если на 3D-модели или картограмме обнаружены неточности автоматического разделения точек, вернитесь на вкладку «2D Схема в плане» и скорректируйте их в один клик с помощью рамки выделения.

Как быстро переназначить группу точек:

  • В любом режиме: зажмите клавишу Shift и протяните прямоугольную рамку левой кнопкой мыши (Shift + ЛКМ).
  • Через список режимов: переключите выпадающий список мыши на «6. Рамка выделения (Shift+ЛКМ)» — тогда рамка строится обычной протяжкой ЛКМ без зажатия клавиш.
  • Все точки, попавшие внутрь рамки, подсвечиваются ярким янтарным ореолом.
  • Над схемой автоматически появляется плавающая панель управления со счётчиком выделенных точек:
    • [▼ В нижнюю] — переводит все выделенные точки в нижнюю поверхность (дно выемки / основание насыпи, маркер v).
    • [▲ В верхнюю] — переводит все выделенные точки в верхнюю поверхность (дневная земля / гребень насыпи, маркер ^).
    • [❌ Удалить] — удаляет все выделенные точки из проекта (с окном подтверждения). Точки также можно удалить нажатием клавиши Delete.
    • [✕ Снять] — снимает выделение со всех точек.
  • Аналогичные кнопки пакетного назначения и удаления (❌) продублированы в блоке «Контур сшивания» на боковой панели.
  • Все операции выделения и назначения мгновенно откатываются сочетанием клавиш Ctrl+Z или кнопкой ↩ Отмена.

1.4. Переопределите треугольники

Классическая триангуляция Делоне не учитывает геоморфологию рельефа (бровки откосов, тальвеги). При необходимости скорректируйте сетку треугольников, для этого перейдите на вкладку «TIN Триангуляция» и откорректируйте их:

  1. Вручную — кликните ПКМ по ребру между двумя треугольниками для его переброски на противоположную диагональ. Объём пересчитывается автоматически.
  2. Автоматически — нажмите ⚡ Оптимизация на верхней панели TIN. При необходимости настройте минимальный угол треугольника (поле Угол:) и число итераций (поле Итер:). Объём также пересчитывается автоматически.
  3. Для скрытия/раскрытия нижней таблицы треугольников — кнопка ▲ Список, для отмены исключения треугольников — кнопка ↩ Сброс, для возврата к исходной триангуляции Делоне — кнопка 🔄 Делоне.

Всё готово. Объём рассчитан.

Автоматическое распознавание осей

Порядок столбцов определяется автоматически по разрядности чисел (МСК, российская геодезическая практика):

  • Север X — 6 знаков в целой части (например, 439007.646).
  • Восток Y — 7 знаков в целой части (например, 2281305.861).
  • Высота H/Z — 3 знака и менее в целой части (например, 145.32).
  • ID — буквенно-цифровой идентификатор точки.

Автоматический переход к переопределению колонок: если файл содержит координаты в локальной или условной системе (например, строительная площадка с 3–5 знаками до запятой вида 3299.1, 1616.2) либо нестандартный порядок полей, программа сразу открывает диалог 🔀 Переопределение координат (X, Y, Z) с предпросмотром файла. Никаких лишних окон с ошибками не выводится: пользователь сразу видит таблицу исходных строк, наглядно указывает соответствие столбцов (ID, X, Y, Z) или меняет X ↔ Y одной кнопкой, после чего нажимает «✓ Применить координаты».

При раздельном импорте двух поверхностей (Верх / Низ...) авто-диалог откроется для каждого файла с нестандартными координатами индивидуально, с указанием имени файла в заголовке окна.

Выбранные настройки колонок автоматически сохраняются в проект .volproj, поэтому при последующих открытиях проекта диалог больше не тревожит пользователя. Также окно переопределения в любой момент можно вызвать вручную кнопкой 🔀 Настройка осей и колонок (X, Y, Z)... в левой панели или 🔀 Колонки... на вкладке «Таблица точек».

Варианты загрузки и разделения поверхностей

  • Один файл — общий массив точек (с учётом уклона рельефа)

    Используется при классической тахеометрической или спутниковой съёмке выемки, траншеи или насыпи в один файл:

    • Локальная 2D-интерполяция границы (Delaunay + IDW): при продольном уклоне местности (например, траншея с перепадом высот с севера на юг) простое глобальное среднее приводило бы к ошибке — дно в верхней части траншеи оказывалось выше порога и помечалось как земля. В GeoVolume Pro реализована локальная триангуляция Делоне по контуру сшивания: для каждой внутренней точки вычисляется точная локальная отметка естественной земли $Z_{\text{bound}}(x, y)$.
    • Адаптивный динамический порог $\Delta Z$: программа автоматически подбирает порог глубины (от 0.08 до 0.20 м в зависимости от перепада отметок). Точки дна гарантированно получают маркер v (нижняя поверхность), а бровка — ^ (верхняя).
    • Кнопка «Авто-Z»: позволяет в любой момент пересчитать разделение точек с использованием локальной интерполяции контура.
    • Приоритет ручных правок: любые назначения, сделанные пользователем (через рамку выделения или таблицу), имеют абсолютный приоритет #1.
  • Два файла (кнопка «Верх / Низ...») — раздельные независимые съёмки

    Применяется для сравнения исходной поверхности земли и фактической исполнительной съёмки:

    • Гарантированная изоляция массивов: 100% точек первого файла попадают в верхнюю поверхность, 100% точек второго файла — в нижнюю. Исключена потеря крайних точек контура и перекрёстное загрязнение высот на границе.
    • Контур как граница интегрирования: контур сшивания используется исключительно как плановый (2D) полигон ограничения расчётной сетки, не искажая 3D-высоты поверхностей.

4. Интерфейс и вкладки

Левая панель скомпонована в 4 логических блока: 1. Тип работ (Выемка / Насыпь), 2. Исходные данные и контур сшивания, 3. Параметры и запуск расчёта, 4. Результаты расчёта (поле увеличено по высоте до 16 строк для полного отображения всех параметров без прокрутки), а также кнопка 🌓 Тёмная / Светлая тема вверху левой панели. Заголовки блоков разделены удобными полустрочными отступами.
В правом верхнем углу строки выбора вкладок дополнительно расположены кнопка 📖 Справка (HTML) и компактный контрастный переключатель темы оформления 🌓 (светлый на тёмной теме, тёмный на светлой). Обе кнопки переключения темы полностью синхронизированы.
Правая панель — вкладки с визуализациями (2D, 3D, Картограмма, TIN), таблицей точек и встроенными в нижнюю часть холстов панелями инструментов.

💡 Разворачивание вкладки на полный экран:
Двойной щелчок ЛКМ по названию любой вкладки в верхней панели (2D Схема в плане, 3D Поверхности, Картограмма масс, Таблица точек, TIN Триангуляция) разворачивает её на полный экран: левая панель управления автоматически скрывается, а окно распахивается во весь экран.
В строке инструментов графиков (по центру, между кнопками сохранения и координатами курсора) отображаются объёмы насыпи, выемки и итоговый баланс.
Возврат к обычному экрану программы выполняется точно так же — повторным двойным щелчком по названию вкладки или нажатием клавиши Esc.
⚙️ Управление видимостью поверхностей («▲ Верхняя» / «▼ Нижняя»):
Переключатели расположены непосредственно на холстах в правом верхнем углу вкладок (доступны как в обычном оконном, так и в полноэкранном режиме), что позволило полностью разгрузить левую панель. Они автоматически адаптируются к геоморфологии объекта (выемка или насыпь):
  • 2D Схема в плане:
    • Выключены обе: отображается только чистый контур сшивания (без номеров обхода и отметок пикетов).
    • Включена Верхняя: для выемки — контур и точки дневной поверхности; для насыпи — контур и точки тела/гребня насыпи с отметками H.
    • Включена Нижняя: для выемки — контур и точки дна котлована с отметками H; для насыпи — контур и точки подошвы/основания.
    • Включены обе: полный набор всех пикетов с номерами и отметками.
  • 3D Поверхности: при отключении обеих — только 3D-контур сшивания; при выборе верхней/нижней/обеих — соответствующие 3D-модели поверхностей.
  • Картограмма масс:
    • Выключены обе: отображается контур сшивания.
    • Включена Верхняя: для выемки — верхняя плоскость без сетки; для насыпи — поверхность насыпи с наложенной сеткой треугольников TIN.
    • Включена Нижняя: для выемки — дно котлована с сеткой треугольников TIN; для насыпи — основание без сетки.
    • Включены обе: полная картограмма мощности ΔH с сеткой треугольников TIN.
  • TIN Триангуляция:
    • Выключены обе: только контур сшивания.
    • Включена Верхняя: для выемки — верхняя плоскость контура; для насыпи — контур, точки тела насыпи (без подписей) и треугольники TIN насыпи.
    • Включена Нижняя: для выемки — контур, точки дна котлована (без подписей) и треугольники TIN котлована; для насыпи — основание без треугольников.
    • Включены обе: полный вид с точками без подписей и сеткой треугольников.
📖 Интерактивная справка:
В шапке программы (над переключателями поверхностей) размещена кнопка 📖 Справка (HTML). Одно нажатие открывает данное руководство в системном веб-браузере.

4.1. 2D Схема в плане

Основное рабочее окно. Горизонтальная ось — Восток Y, вертикальная — Север X (стандарт топографических планов). Координаты курсора отображаются с точностью 1 мм.

Режим мышиДействие ЛКМ / Клавиши
1. Интерактивный контурПоследовательный клик по точкам формирует замкнутый контур сшивания (красный пунктир)
2. Авто-контур (Выпуклая оболочка)Автоматическое построение границы по крайним точкам (Convex Hull)
3. Назначение: Верхняя поверхностьПеревод точки в верхний слой (маркер ^)
4. Назначение: Нижняя поверхностьПеревод точки в нижний слой (маркер v)
5. Добавить точкуОткрывает диалог ручного ввода координат и отметки новой точки
6. Рамка выделения (Shift+ЛКМ)Прямоугольная рамка для массового выделения точек и пакетного назначения поверхностей

Особенности интерактивной работы на 2D-схеме

  • Пакетное управление (Рамка выделения): зажав Shift + ЛКМ (или выбрав режим 6), растяните рамку вокруг нужных пикетов. Они подсветятся янтарным ореолом, а на плавающей панели над чертежом станут доступны кнопки [▼ В нижнюю], [▲ В верхнюю], [❌ Удалить] и [✕ Снять]. Команды назначения и отмены мгновенно откатываются по Ctrl+Z.
  • Контекстное меню по ПКМ на точке: клик правой кнопкой мыши по любой точке на схеме открывает меню быстрого выбора: ▲ Перенести в верхнюю поверхность, ▼ Перенести в нижнюю поверхность или ❌ Удалить точку. Это позволяет моментально исправлять принадлежность точек прямо на чертеже без открытия таблицы.
  • Мгновенный отклик при выделении контура (Blitting): интерактивное построение контура, протяжка эластичных линий и рамка выделения оптимизированы с помощью послойного Matplotlib Blit-кэширования. Выделение работает плавно даже на больших наборах данных.
  • Кнопка «Сброс контура»: прямо под легендой «Контур сшивания» на вкладке схемы добавлена заметная красная кнопка Сброс контура. Она позволяет моментально очистить контур без необходимости перехода на левую панель.
  • Адаптивный LOD подписей точек (Level of Detail) и кнопка «🏷️ Подписи»: при работе с большими облаками данных (тысячи точек) текстовые подписи номеров и отметок автоматически оптимизированы: при общем плане отображаются контрастные маркеры точек и номера вершин контура (#1, #2, ...), исключая зависания и наложение текста в сплошное пятно. При приближении к локальной группе пикетов (≤ 50 точек в кадре) подписи появляются автоматически, обеспечивая идеальную читаемость. Кнопка 🏷️ Подписи в правом верхнем углу позволяет принудительно переключать режим (Авто / Вкл / Выкл).
  • Мгновенная инспекция точек под курсором: при наведении мыши на любую точку (даже на самом мелком общем плане при отключенных подписях) в нижней панели координат навигации моментально (за 0.01 мс через KD-дерево) высвечивается точная карточка пикета: [Точка 105: H=124.500 (Верх)] X (Север): ... Y (Восток): ....
  • Векторизация TIN и рамки выделения: алгоритмы геометрической выборки точек рамкой и отрисовка поверхностей на вкладке TIN полностью векторизованы через NumPy, обеспечивая плавную работу и моментальный отклик на облаках до 50 000+ точек.
  • Интеллектуальное скрытие подписей у границ: при детальном увеличении масштаба (зуме) или сдвиге схемы подписи номеров и отметок высот автоматически скрываются, как только сама точка выходит за границы холста. Это гарантирует чистый вид без наползания текста на рамки и оси.
  • Кнопка «Авто-Z»: выполняет интеллектуальное разделение точек с использованием 2D-триангуляции контура и локальной барицентрической интерполяции, исключая ошибки на линейных траншеях с продольным уклоном.
  • ПКМ на свободном месте схемы (или кнопка ↩ Отмена / Ctrl+Z) — отменяет последнее действие (добавление вершины, перемещение или пакетное переназначение).

4.2. TIN Триангуляция

Отображение поверхностей

  • Красные точки / сетка — нижняя поверхность.
  • Видимость управляется переключателями «▲ Верхняя» / «▼ Нижняя» в правом верхнем углу холста.

Переброска рёбер вручную (Edge Flip)

При выполнении условий ребро заменяется на противоположную диагональ. Объёмы, 3D-модель и картограмма пересчитываются автоматически. Операция записывается в стек Undo.

4.3. 3D Поверхности

Активные поверхности задаются чекбоксами «Верхняя» / «Нижняя». Определение физически верхней и нижней поверхности выполняется по сравнению средних высот (не по объёмам).

  • При включении обеих поверхностей — обе отображаются сеткой (plot_surface) для корректной прозрачности.
  • При включении одной верхней — используется TIN (если доступен), иначе сетка.
  • Масштаб всех осей задаётся по фактическому диапазону данных (5% отступ по X/Y, 15% по Z).

4.4. Картограмма масс

Цветовая карта распределения толщины слоя ΔH = Zверх − Zниз. Swap верхней/нижней поверхности для выемок и насыпей рассчитывается по сравнению средних высот.

  • При включении обеих поверхностей — карта мощности ΔH (colormap viridis: тёмно-синий — малая толщина, жёлто-зелёный — большая).
  • При включении одной поверхности — карта абсолютных высот.
  • Поверх картограммы накладываются рёбра TIN (при наличии пользовательских перебросок).
  • Граничный контур — красный пунктир. Соотношение осей 1:1.

5. Методика расчёта

  1. Центрирование координат — перед триангуляцией вычитается локальный нуль (X₀, Y₀). Устраняет погрешности округления при работе с миллионными геодезическими координатами.
  2. Триангуляция — scipy.spatial.Delaunay. При наличии пользовательских перебросок рёбер формируется кастомная структура симплексов. Треугольники за пределами контура исключаются.
  3. Интерполяция — высоты верхней поверхности вычисляются через matplotlib.tri.LinearTriInterpolator на регулярной сетке с шагом Δg (по умолчанию 0.20 м).
  4. Интегрирование — для каждого узла сетки: мощность ΔH = Zверх − Zниз, объём ячейки ΔV = ΔH · Sячейки.
