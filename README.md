**GeoVolume Pro v1.0.1** — инженерная программа для расчета объемов земляных масс (насыпь, выемка, баланс) по геодезическим координатам (TXT, CSV, DAT, XYZ). Разработана на классическом графическом стеке Tkinter / Win32 GDI для гарантированной работы на всех версиях Windows, включая Windows 7, 8 и 8.1.

## Возможности версии 1.0.1

* **Совместимость:** 100% поддержка Windows 7 SP1, Windows 8, Windows 8.1, 10 и 11.
* **Методы расчета:** послойная триангуляция Делоне (TIN) с обрезкой по контуру и численное интегрирование по регулярной сетке.
* **Импорт координат:** гибкое чтение любых разделителей, автоопределение осей (X Север, Y Восток, H Высота), диалог ручной настройки колонок.
* **Интерактивный контур (2D схема):**
  * Встраивание точки в контур двойным кликом ЛКМ без самопересечений.
  * Перенос вершины контура зажатой ПКМ.
  * Прямоугольная рамка выделения (`Shift + ЛКМ`).
  * Контекстное меню ПКМ для одиночных точек и групп точек.
  * Отмена действий (`Ctrl + Z`).
* **Геодезические треугольники (TIN):** полноэкранная триангуляция и отдельное окно таблицы треугольников с фильтрацией и ручным исключением.
* **3D Моделирование:** скульптурная визуализация рельефа, переключатели поверхностей в тулбаре, полноэкранный чистый 3D-режим без координатных сеток.
* **Картограмма масс:** изогипсы, цветовой градиент мощности слоя $\Delta H$, изолинии нулевых работ.
* **Проекты:** автоматическая организация проектов в папке `Projects/`, запоминание активного проекта и авто-расчет при запуске.

## ⌨️ Горячие клавиши

| Действие | Где работает | Клавиши / Мышь |
| :--- | :--- | :--- |
| **Выделение рамкой** | 2D Схема | `Shift + ЛКМ` (протяжка) |
| **Встраивание в контур** | 2D Схема | `Двойной клик ЛКМ` по точке |
| **Перенос вершины контура** | 2D Схема | Зажать `ПКМ` на вершине и перетащить |
| **Контекстное меню** | 2D Схема | `ПКМ` по точке или пустому месту |
| **Отмена действия (Undo)** | Все вкладки | `Ctrl + Z` |
| **Удаление точек** | 2D Схема | `Delete` |
| **На весь экран / Выход** | Вкладки / 3D | `Двойной клик ЛКМ` / `Esc` |
| **Зум / Панорама** | 2D, TIN, Картограмма | Колесо мыши / Зажатая `ЛКМ` |
| **Вращение 3D** | 3D Поверхности | Зажатая `ЛКМ` |

## 💻 Запуск из исходного кода

```powershell
git clone -b v1.x https://github.com/r888tx-cpu/volume_calculator.git
cd volume_calculator
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python volume_calc.py                # GUI
python volume_calc.py points.txt     # CLI расчет
```

Тесты: `pytest tests/`
