**GeoVolume Pro** — современное настольное приложение для высокоточного расчета объемов земляных масс (насыпь, выемка, баланс) по геодезическим координатам пикетов (TXT, CSV, DAT, XYZ).

---

## ⚡ Быстрый старт (Готовая сборка для Windows)

Для запуска **не требуется** устанавливать Python или дополнительные библиотеки:

1. Скачайте архив релиза:  
   👉 [**GeoVolumePro_v1.0.0_win64.zip**](https://github.com/r888tx-cpu/volume_calculator/releases/download/v1.0.0/GeoVolumePro_v1.0.0_win64.zip) *(57.7 МБ)*
2. Распакуйте архив в любую папку.
3. Запустите файл **`GeoVolumePro.exe`**.

## 🌟 Ключевые возможности

* **Два метода расчета объемов**:
  * **TIN (прямой)** — послойная триангуляция Делоне без потери точности и искажений рельефа.
  * **Регулярная сетка** — билинейная интерполяция высот с настраиваемым шагом.
* **Интерактивный контур сшивания**:
  * Автоматическое построение выпуклой границы (Convex Hull).
  * Ручное добавление и удаление вершин, встраивание в ребро (двойной клик) и интерактивное перетаскивание вершин (ПКМ) с аппаратным ускорением (Blitting).
* **Разделение поверхностей**:
  * Автоматическая классификация естественной земли и дна выемки с учетом продольного уклона местности (локальная интерполяция Делоне по контуру).
  * Ручное и пакетное (рамка `Shift + ЛКМ`) переназначение точек в верхнюю / нижнюю поверхность.
  * Быстрое контекстное меню по ПКМ и мгновенный откат любых действий (`Ctrl + Z`, кнопка `[✕ Отмена]`).
* **Визуализация и экспорт**:
  * 2D-схема в плане, интерактивный 3D-просмотр рельефа, картограмма земляных масс и схема триангуляции (TIN).
  * Экспорт графики в высоком разрешении (PNG, 300 DPI) и детальных текстовых отчетов (`*_report.txt`).
  * Адаптивная темная и светлая темы оформления.

## 💻 Запуск из исходного кода

При необходимости запустить проект из исходников:

```bash
# Клонирование репозитория
git clone https://github.com/r888tx-cpu/volume_calculator.git
cd volume_calculator

# Установка зависимостей
pip install -r requirements.txt

# Запуск графического интерфейса
python volume_calc.py
```

Расчет в пакетном режиме (CLI) без графического интерфейса:
```bash
python volume_calc.py coordinates.txt
```
