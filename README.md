# Volume Calculator — Программа расчета объемов земляных масс и 3D-моделирования рельефа

Профессиональный инженерный программный комплекс для вычисления объемов насыпей, выемок и баланса земляных масс между двумя топографическими поверхностями (верхней и нижней), сшитыми по граничным точкам внешнего контура.

Программа разработана специально для маркшейдеров, геодезистов, инженеров-проектировщиков и строителей. Она сочетает строгость аналитических геодезических методов (TIN-триангуляция Делоне, структурные линии, численное интегрирование по регулярной сетке) с современным интерактивным графическим интерфейсом и эстетичной 3D-визуализацией.

## 1. Ключевые возможности

- **Универсальный импорт координат**: гибкое чтение форматов геодезических приборов (Тахеометры, ГНСС) и CAD-систем с любыми разделителями.
- **Интеллектуальное распознавание осей**: автоматическое распознавание Север $X$ (6 знаков до запятой) и Восток $Y$ (7 знаков до запятой) при любом порядке столбцов.
- **Интерактивное задание контура сшивания**: объединение рельефа по замкнутому контуру вручную по клику мыши либо автоматическим построением выпуклой оболочки.
- **Геодезическая триангуляция (TIN)**: построение сети треугольников внутри контура с возможностью ручной переброски рёбер (Edge Flipping) по клику правой кнопки мыши для моделирования бровок, тальвегов и водоразделов.
- **Картограмма земляных масс**: наглядная цветовая карта мощности слоя $\Delta H = Z_{верх} - Z_{низ}$ с изолиниями, цветовой шкалой глубин/высот и наложением сетки TIN.
- **Полноэкранный 3D-просмотр**: скульптурная 3D-модель рельефа на 100% площади экрана в тёмной CAD-теме без отвлекающих координатных коробок и сеток.
- **Два режима работы**: полноценный GUI-интерфейс и консольный CLI-режим для пакетной обработки файлов через скрипты.

## 2. Особенности импорта геодезических данных

Модуль парсинга (`geo_parser.py`) разработан с учётом реальной практики полевых съемок и многообразия форматов экспорта из геодезического оборудования.

### 2.1. Поддерживаемые форматы файлов
- **Расширения файлов**: `.txt`, `.csv`, `.dat`, `.xyz`, `.pts`, `.sdr` (текстовый экспорт).
- **Кодировка**: UTF-8, UTF-8 с BOM, Windows-1251 (CP1251), ASCII. Программа автоматически очищает маркеры порядка байтов (`\ufeff`).
- **Разделители данных**: запятая (`,`), точка с запятой (`;`), знак табуляции (`\t`) или произвольное количество пробелов. Десятичный разделитель чисел может быть как точкой (`.`), так и запятой (`,`).

### 2.2. Правила автоматического распознавания осей (X, Y, Z/H)
В отечественной геодезии (СК-42, СК-95, МСК регионов) координаты имеют характерную разрядность:
1. **Север $X$**: ровно **6 знаков** в целой части до точки (например, `439007.646`).
2. **Восток $Y$**: ровно **7 знаков** в целой части до точки, где первая цифра обычно обозначает номер зоны (например, `2281305.861`).
3. **Высота $H$ / $Z$**: **3 или менее знаков** в целой части (например, `145.320` или `-2.15`). Идёт после координат $X$ и $Y$.
4. **Имя точки (ID)**: буквенно-цифровой идентификатор. Поддерживаются составные геодезические имена вида `201_т201`, `т-15`, `Опора_4` и т.д.

Программа **автоматически понимает любой порядок столбцов**:
```text
ID, X (6 цифр), Y (7 цифр), H
ID, Y (7 цифр), X (6 цифр), H
1, 201, 2281305.861, 439007.646, 154.20
```

### 2.3. Ручное переопределение колонок (Диалог «🔀 Колонки»)
Если в вашем файле нестандартная местная система координат (например, локальная строительная сетка, где и $X$, и $Y$ имеют одинаковое число знаков):
1. Нажмите кнопку **`🔀 Настройка осей и колонок (X, Y, Z)...`** в левой панели или кнопку **`🔀 Колонки...`** на вкладке «Таблица точек».
2. В открывшемся окне отобразится табличный предпросмотр реальных строк вашего файла.
3. Выберите из выпадающих списков, какая именно колонка файла отвечает за **ID**, **Север X**, **Восток Y** и **Высоту Z**.
4. Нажмите «Применить» — файл моментально перечитается с указанными настройками.

### 2.4. Варианты загрузки поверхностей
- **Один файл (совместная съемка)**: загружается общий массив точек. Программа автоматически классифицирует точки на контурные и внутренние, либо позволяет разбить их по высоте кнопкой **«Авто-Z»**.
- **Раздельные файлы («Верх/Низ...»)**: загрузка двух независимых файлов — отдельно файл съемки до начала работ (исходная поверхность / котлован) и отдельно съемка после завершения работ (насыпь / верхний слой). Точки контура связывают обе поверхности.

## 3. Структура проектов и организация данных

Для предотвращения путаницы в съемках реализована автоматическая файловая структура проектов:
- Все проекты группируются в корневом каталоге **`Projects/`**.
- Папка каждого проекта именуется по стандарту: **`ДД.ММ.ГГГГ_ИмяПроекта/`** (например, `Projects/08.09.2026_Насыпь_Карьер_1/`).
- Внутри папки проекта автоматически сохраняются:
  - Исходные файлы координат (`.txt`, `.csv`).
  - Файл состояния проекта **`.volproj`** (в формате JSON), содержащий информацию о выбранном контуре, классификации точек, ручных перебросках ребер TIN и параметрах сетки.
  - Итоговые текстовые отчеты расчетов (`report_*.txt`).
  - Экспортированные чертежи и схемы (`plot_*.png`).

При запуске программа автоматически сканирует каталог `Projects/` и заполняет выпадающий список проектов в левой панели.

### 4.1. 2D Схема в плане (X / Y)
Основное рабочее окно для контроля геометрии объекта и формирования контура сшивания.

- **Координатные оси**: по горизонтали отложен **Восток $Y$**, по вертикали — **Север $X$** (в строгом соответствии с геодезическими правилами отображения топографических планов).
- **Статусная строка**: при движении курсора под схемой отображаются точные значения `X (Север): ... м` и `Y (Восток): ... м` с точностью до 1 мм.
- **Подписи точек**: отображается имя точки и ее высотная отметка (например, `т201 (145.32)`).
- **Режимы работы (выпадающий список в блоке 2 левой панели)**:
  1. *Интерактивный контур (ЛКМ)*: последовательный щелчок по точкам на схеме формирует замкнутый полигон границы сшивания поверхностей.
  2. *Авто-контур (Выпуклая оболочка)*: автоматическое определение границы по крайним точкам объекта (алгоритм Convex Hull).
  3. *Назначение: Верхняя поверхность*: клик по точке принудительно относит ее к верхнему слою.
  4. *Назначение: Нижняя поверхность*: клик по точке принудительно относит ее к подошве/дну.
  5. *Добавить точку*: клик в любом месте плана открывает окно создания дополнительной высотной отметки.
- **Интерактивное редактирование контура без сброса**:
  - **Встраивание точки в ближайшее ребро**: **двойной клик ЛКМ** по свободной точке — точка автоматически встраивается в ближайший отрезок контура с сохранением порядка обхода и без самопересечений.
  - **Замена вершины контура (перетаскивание)**: зажать **ПКМ на вершине контура** и перетащить курсор на новую точку — контур плавно перестраивается.
  - **Удаление вершины**: одиночный клик **ЛКМ** по точке контура.
- **Навигация**:
  - **Зум колесиком мыши**: масштабирование вокруг точки, на которую указывает курсор (Zoom under cursor).
  - **Панорамирование схемы**: зажатие **ЛКМ** и перетаскивание схемы.
  - **Отмена (Undo)**: одиночный клик **ПКМ** или кнопка «↩ Отмена» отменяет любое действие с контуром.

### 4.2. Геодезические треугольники (TIN) и переброска граней (Edge Flipping)

Вкладка **«Геодезические треугольники (TIN)»** предназначена для детального контроля и редактирования топографической поверхности.

#### Особенности построения TIN:
1. **Обрезка по контуру**: в расчет попадают **только те треугольники, которые лежат строго внутри выбранного контура границы**. Внешние паразитные длинные треугольники триангуляции Делоне автоматически отсекаются.
2. **Единая компактная панель инструментов TIN**:
   - `🔍 В фокус` — возвращает схему треугольников в центр экрана с оптимальным охватом всего объекта.
   - `✂ Исключить` / `✂ Восстановить` — выключение/включение выбранного треугольника из расчетной модели.
   - `↩ Сброс` — возвращает все выключенные треугольники в активное состояние.
   - `🔄 Делоне` — сброс всех ручных изменений к исходной классической триангуляции Делоне.
   - `▲ Список` / `▼ Список` — свернуть/развернуть таблицу треугольников для максимизации области чертежа.
   - `⚡ Оптимизация` — автоматический перебор внутренних рёбер по критерию максимизации (выемка) или минимизации (насыпь) объёма с контролем минимального угла треугольников (поле `Угол:`) и числа проходов (поле `Итер:`).

#### Переброска граней треугольников (Edge Flipping по клику ПКМ):
> [!IMPORTANT]
> Классическая триангуляция Делоне соединяет точки по критерию пустого описанного круга, игнорируя геоморфологию. В результате между бровками откосов или водоразделами программа может провести ребро поперек реальной складки рельефа (например, соединить точки дна вместо бровки).

В нашей программе реализован инструмент интерактивной переброски ребра:
1. Наведите курсор мыши на внутреннее ребро между двумя треугольниками, которое вы хотите переопределить (например, грань между точками 60 и 52).
2. Нажмите **правую кнопку мыши (ПКМ)** прямо по этому ребру.
3. Программа выполняет автоматическую математическую проверку:
   - Ребро не является внешним контуром границы объекта.
   - Четырехугольник, образованный двумя смежными треугольниками, является **строго выпуклым** (новое соединяющее ребро будет лежать внутри контура).
4. Ребро мгновенно заменяется на противоположную диагональ (например, ребро теперь соединяет точки `т201` и `190`).
5. **Автоматический перерасчет**: объём земляных масс, 3D-модель и картограмма автоматически пересчитываются и обновляются с учётом новой геометрии!
6. Операция сохраняется в стек отмены (`Undo`).

### 4.3. 3D Поверхности и полноэкранный чистый 3D-просмотр

Вкладка **«3D Поверхности»** обеспечивает наглядное пространственное восприятие выемки и насыпи.

#### Встроенный 3D-график:
- Отображает верхний рельеф с наложенной треугольной сеткой, полупрозрачную нижнюю поверхность и яркий салатовый контур сшивания.
- Кнопки панели:
  - `🔄 Исходный ракурс`: сброс углов камеры к изометрическому виду по умолчанию (`elev=35°`, `azim=-60°`).
  - `🔝 Вид сверху (План)`: мгновенный переход в ортогональный вид строго сверху (`elev=90°`, `azim=-90°`).
  - `⛶ На весь экран (Чистый 3D вид)`: открытие специализированного полноэкранного просмотрщика.
  - **Двойной клик ЛКМ** по 3D-графику также мгновенно открывает полноэкранный режим.

#### Полноэкранный режим «Чистый 3D вид» (`FullScreen3DViewer`):
Разработан специально для комфортного эстетичного анализа рельефа без графического шума:
- **Никаких координатных коробок**: серые непрозрачные координатные стенки, засечки осей, числовые подписи и сетки полностью отключены (`ax.set_axis_off()`). Вся область экрана отдана исключительно трехмерной фигуре рельефа.
- **Тёмная дизайнерская CAD-тема (`#1a1e24`)**:
  - *Верхняя поверхность*: благородная медная цветовая гамма (`copper`) с аккуратной полупрозрачной отмывкой граней треугольников.
  - *Нижняя поверхность*: полупрозрачный ледяной оттенок (`Blues_r`), позволяющий заглянуть сквозь верхний слой и оценить реальную толщину выемки/насыпи.
  - *Контур границы*: неоновая салатовая линия (`#2ecc71`) толщиной 3.5 px.
- **Управление в полноэкранном окне**:
  - **Вращение 360°**: зажмите **ЛКМ** и двигайте мышь в любом направлении.
  - **Плавный зум**: вращайте **колесико мыши** (приближение к интересующему участку котлована или насыпи).
  - **Панорамирование**: зажмите **ПКМ** или колесико мыши для смещения модели.
  - `✕ Закрыть (Esc)`: выход из полноэкранного режима (или нажатие клавиши `Esc`).
  - `⛶ Во весь экран (F11)`: переключение между оконным и безрамочным режимом на весь монитор.
  - `👁 Оси и сетка: ВЫКЛ/ВКЛ`: возможность при необходимости одним нажатием вернуть координатные шкалы и отметки высот.
  - `🌓 Тема: Тёмная/Светлая`: переключение на классический белый фон для снятия скриншотов в отчеты.

### 4.4. Картограмма земляных масс

Вкладка **«Картограмма земляных масс»** формирует классический план распределения толщин слоя:
- Значение в каждой точке: $\Delta H = Z_{верх} - Z_{низ}$.
  - Положительные значения ($\Delta H > 0$) соответствуют **насыпи** (заливка от желтого к красному).
  - Отрицательные значения ($\Delta H < 0$) соответствуют **выемке** (синие и фиолетовые тона).
  - Нулевая линия ($\Delta H = 0$) обозначает линию нулевых работ (границу между выемкой и насыпью).
- **Сетка TIN**: поверх картограммы накладываются тонкие полупрозрачные рёбра геодезических треугольников, что позволяет видеть влияние переброшенных граней на изолинии мощности.
- **Цветовая шкала (Colorbar)**: размещена справа с точной градуировкой в метрах.
- **Геодезический масштаб**: строго сохраняются пропорции осей 1:1 (`aspect='equal'`).

### 4.5. Таблица точек и ручное редактирование

Вкладка **«Таблица точек»** содержит структурированный список всех геодезических пикетов:
- Столбцы: № п/п, Имя / ID, Север $X$ (м), Восток $Y$ (м), Высота $H$ (м), Тип поверхности.
- Панель инструментов:
  - `➕ Добавить точку`: диалог ручного ввода координат нового пикета.
  - `✏️ Редактировать` (или **двойной клик** по строке таблицы): корректировка отметок или имени точки.
  - `🗑️ Удалить точку`: удаление ошибочно заснятого пикета.
  - `🔄 Сменить тип`: циклическое переключение статуса точки (`auto` $\rightarrow$ `top` $\rightarrow$ `bottom` $\rightarrow$ `auto`).
  - `🔀 Колонки...`: переназначение соответствия осей файла.

## 5. Методика математического расчета

Расчетный модуль (`volume_engine.py`) реализует гибридный метод, сочетающий геометрическую точность нерегулярных треугольных сеток с устойчивостью численного двумерного интегрирования:

1. **Топологическое сшивание**:
   - Точки граничного контура являются общими для верхней и нижней поверхностей, замыкая объемную фигуру в герметичное геометрическое тело (принцип водонепроницаемого тела — Watertight Solid).
2. **Защита от потери точности чисел с плавающей точкой**:
   - Перед триангуляцией координаты центрируются вычитанием локального нуля $(X_0, Y_0)$, что устраняет погрешности округления при операциях с миллионными геодезическими координатами.
3. **Триангуляция и учет ручных перебросок рёбер**:
   - Построение сетки $TIN$ с помощью `scipy.spatial.Delaunay`.
   - При наличии пользовательских перебросок рёбер формируется кастомная структура симплексов.
   - Вычисление высот верхнего слоя производится через кусочно-линейную интерполяцию `matplotlib.tri.LinearTriInterpolator` строго внутри каждого треугольника, что гарантирует сохранение всех перегибов рельефа.
4. **Интегрирование по элементарным призмам**:
   - Область внутри контура дискретизируется адаптивной регулярной сеткой с шагом $\Delta g$ (по умолчанию 0.20 м).
   - Для каждого узла сетки вычисляются $Z_{верх}$, $Z_{низ}$ и локальная мощность $\Delta H = Z_{верх} - Z_{низ}$.
   - Элементарный объем ячейки: $\Delta V = \Delta H \cdot S_{ячейки}$.
5. **Итоговые показатели**:
   - **Объем насыпи ($V_{fill}$)**: сумма $\Delta V$ для всех ячеек, где $\Delta H > 0$.
   - **Объем выемки ($V_{cut}$)**: сумма $|\Delta V|$ для всех ячеек, где $\Delta H < 0$.
   - **Результирующий баланс ($V_{net}$)**: $V_{fill} - V_{cut}$.
   - **2D Площадь в плане**: вычисляется по формуле Гаусса (Shoelace formula).
   - **3D Площадь поверхностей**: вычисляется как сумма площадей трехмерных пространственных треугольников в пространстве $\mathbb{R}^3$ через векторное произведение векторов граней:
     $$S_{3D} = \frac{1}{2} \sum_{i} |(\mathbf{p}_1 - \mathbf{p}_0) \times (\mathbf{p}_2 - \mathbf{p}_0)|$$

## 7. Установка, запуск и сборка исполняемого файла (.exe)

### 7.1. Системные требования
- ОС: Windows 10 / 11 (64-bit).
- Python: версия 3.10, 3.11, 3.12, 3.13 или 3.14.

### 7.2. Установка зависимостей
```bash
pip install -r requirements.txt
```
Основные библиотеки:
- `numpy >= 1.25` — матричные операции и обработка массивов координат.
- `scipy >= 1.11` — триангуляция Делоне, выпуклые оболочки и интерполяторы.
- `matplotlib >= 3.8` — графический рендеринг 2D-схем, картограмм и 3D-поверхностей.
- `pyinstaller >= 6.0` — сборка автономного `.exe` пакета.

### 7.3. Запуск программы из исходников
Для запуска приложения с графическим интерфейсом:
```bash
python volume_calc.py
```
или дважды кликните по командному файлу `run_volume_calc.bat`.

Для запуска в консольном пакетном режиме (CLI):
```bash
python volume_calc.py <путь_к_файлу_координат.txt>
```

### 7.4. Сборка автономного исполняемого файла (.exe)
Для сборки готового приложения, не требующего установленного Python:
```powershell
pyinstaller VolumeCalculator.spec --noconfirm
```
Собранный исполняемый файл находится по пути:
```text
C:\Dev\volume_calculator\dist\VolumeCalculator\VolumeCalculator.exe
```
